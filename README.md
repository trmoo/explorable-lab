# 🖐️ 만지는 설명 실험실

값을 바꾸며 스스로 원리를 발견하는 **만지는 설명(익스플로러블 익스플래네이션)** 을
학생이 직접 설계하고, **제미나이 캔버스로 바이브 코딩**해 보는 2차시 정보 수업 앱입니다.

- 고등학교 「정보」 Ⅲ. 알고리즘과 프로그래밍
  - `[12정03-01]` 복잡한 문제를 작은 문제로 분해하고 모델링한다 — 아하 문장·변수·결과로 설계하기
  - `[12정03-09]` 문제 해결을 위한 프로그램을 협력적으로 설계·구현한다 — 캔버스 제작·짝 시험
- 설치 없이 브라우저에서 열립니다. 인터넷은 2차시의 제미나이 캔버스에만 필요합니다.

## 수업 흐름

| 차시 | 탭 | 학생이 하는 일 |
|---|---|---|
| 1 | ① 맛보기 | 만지는 설명이란 · 예시 셋(주사위 · 평균과 중앙값 · 정렬)을 **예측 → 조작 → 설명** 순서로 해 보기 |
| 1 | ② 아이디어 고르기 | 좋은 아이디어 카드 10장 판별 · 바꿀 변수 찾기 |
| 1 | ③ 설계하기 | 주제 · 「아하!」 한 문장 · 예측 질문 · 변수 1~3개 · 화면 · 결과 → 자기 점검 |
| 2 | ④ 프롬프트·제작 | **프로그래머의 눈** 8가지 → 프롬프트 자동 조립(보통판과 나란히) → 캔버스에서 만들고 고친 기록 · 공유 링크 |
| 2 | ⑤ 짝 시험 | 짝이 먼저 예측하고 써 본 뒤 **부숴 보기**(끝값·연타·초기화…) · 고칠 점 |
| 2 | ⑥ 내 활동지 | 배움 정리 · 활동지 HTML 내려받기(제출용) |

화면 주소를 불러 줄 수 있습니다 — 예) `#taste/dice` · `#prompt/make` · `#test`

## 종이 설계지

`docs/만지는설명_설계지.docx` (A4 2쪽) — 1쪽 설계지(1차시), 2쪽 프롬프트 양식 · 프로그래머의 눈 · 고친 기록 · 짝 시험(2차시).
앱의 ③ 설계하기와 칸이 같아서, 종이에 먼저 생각하고 앱에 옮겨 적으면 프롬프트가 조립됩니다.

## 선생님이 수업 전에 확인할 것

1. 학생 학교 계정으로 **gemini.google.com** 에 들어가지는지, 입력창 아래에 **Canvas** 가 보이는지
2. 캔버스 결과를 **공유 링크**로 만들 수 있는지 (학생이 활동지에 붙여 냅니다)
3. 서른 명이 동시에 여러 번 요청해도 사용 한도 안에 드는지

## 학생 기록과 개인정보

- 활동 기록은 그 브라우저에만 남습니다. 공용 컴퓨터라면 ⑥ 내 활동지의 [내 기록 지우기] 를 눌러 주세요.
- 학번·이름은 내려받는 활동지 파일에만 들어갑니다. 다른 컴퓨터에서 이어서 하려면 [이어하기 파일 저장] 을 쓰세요(학번·이름은 들어가지 않습니다).

## 개발

```bash
npm install
npm start            # 개발 서버
npm test             # 시험 (계산·문항·완료 조건·활동지)
npm run check:syntax # 소스 전수 검사
npm run build        # dist/index.html 한 파일 (더블클릭으로 열림)
npm run sheet        # 종이 설계지 다시 만들기 (python-docx 필요)
```
